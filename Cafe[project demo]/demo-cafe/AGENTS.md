# Контекст проекта для ИИ-ассистентов

Этот файл — рабочая заметка для ИИ, который будет помогать с проектом. Это не текст для посетителей сайта.

## Что это за проект

Папка demo-cafe содержит демонстрационный одностраничный сайт кафе для портфолио пользователя. Пользователь предлагает услуги по созданию сайтов малому бизнесу в Узбекистане и будет показывать этот пример владельцам кафе.

Сайт представляет вымышленное кафе Demo Cafe в Ташкенте. Название, адрес, цены, часы работы и отзывы придуманы для демонстрации. Не описывай их как сведения о реальном заведении.

## Где находится сайт

- Точка входа: index.html.
- Стили: style.css.
- Логика и данные: script.js.
- Публичная инструкция: README.md.
- Локальные SVG-заглушки: папка images/.
- main.py в родительской папке не является приложением и не запускает этот сайт.

## Технические ограничения

- Только чистые HTML, CSS и JavaScript. Не добавляй фреймворки, сборщики, сервер или базу данных.
- Сайт должен открываться двойным щелчком по index.html и работать на GitHub Pages или Netlify.
- Локальные файлы подключай относительными путями.
- Не используй внешние фотографии или сторонние библиотеки. Google Fonts — единственный внешний ресурс для оформления; при отсутствии сети должны работать запасные системные шрифты.
- Все чтения и записи localStorage оставляй внутри try/catch.
- Не меняй вымышленные данные на реальные без указаний пользователя.

## Структура и функции

- RU и UZ (латиница) переключаются без перезагрузки. Выбранный язык сохраняется; при ошибке хранилища страница должна продолжать работать.
- Переводы лежат в объектах TRANSLATIONS.ru и TRANSLATIONS.uz в начале script.js. Статический текст в HTML связывается с ними через data-i18n; для доступных названий и alt используются data-i18n-aria и data-i18n-alt.
- CONFIG в начале script.js содержит название, контакты, адреса, ссылки, часы работы, меню и цены. При добавлении блюд сохраняй переводы на обоих языках и изображение-заглушку.
- В каждой категории меню сейчас по четыре блюда. Категории — кофе, десерты, завтраки и основные блюда.
- Изображения меню и шесть изображений галереи — локальные SVG. Сохраняй относительные пути и alt-тексты. Рекомендуемые размеры фотографий и порядок их замены описаны в README.md.
- Галерея открывается в нативном dialog, категории меню управляются мышью и клавиатурой, а блоки появляются через IntersectionObserver.
- В контактах используется нарисованный блок карты со ссылкой на карту; встроенного картографического сервиса нет.

## Важное решение по первому экрану

Пользователь попросил заменить бейдж GOOD MOOD: маленькая чашка терялась в отведённой справа области. Сейчас там чашка, нарисованная inline SVG в index.html, и CSS-анимация пара в style.css. При дальнейших изменениях сохраняй достаточно крупный, хорошо заметный силуэт чашки и мягкий пар. На небольших экранах иллюстрация расположена ниже текста, чтобы не перекрывать заголовок. Учитывай prefers-reduced-motion.

## Доступность и стиль

- Сохраняй мобильную вёрстку, тёплую кремово-коричневую палитру и крупные удобные для нажатия кнопки.
- Используй семантические области, видимый фокус, подписи кнопок-иконок, осмысленные alt и управление клавиатурой.
- Новые видимые тексты добавляй в оба словаря переводов и связывай через подходящие data-i18n-атрибуты. Не оставляй пользовательский текст только на одном языке.
- Учитывай настройку уменьшения анимации.

## Запуск и публикация

Для локального просмотра открой index.html двойным щелчком. Сборка не нужна. Пошаговые инструкции GitHub Pages и Netlify находятся в README.md.

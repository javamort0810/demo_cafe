# Demo Cafe

Одностраничный сайт-пример для кафе в Ташкенте. Проект сделан на чистых HTML, CSS и JavaScript: сборка, сервер и база данных не нужны. Русский и узбекский языки переключаются на странице, выбранный язык запоминается в браузере.

## Как открыть локально

1. Скопируйте или распакуйте папку demo-cafe.
2. Откройте файл index.html двойным щелчком в браузере.
3. Сайт также можно загрузить на GitHub Pages или Netlify по инструкциям ниже.

Страница и все иллюстрации работают без интернета. Google Fonts загружаются только при наличии сети; без неё используются системные шрифты.

## Как адаптировать для кафе клиента

1. **Название и контакты.** В начале script.js измените значения CONFIG.name, phoneDisplay, phoneTel, address.ru и address.uz, telegramUrl, telegramHandle, instagramUrl и mapUrl. Там же в CONFIG.hours задаётся график работы.
2. **Цены.** В массивах CONFIG.menu поменяйте числовые значения price. Они указаны в сумах и форматируются автоматически.
3. **Названия и описания блюд.** Тексты лежат в объектах TRANSLATIONS.ru и TRANSLATIONS.uz файла script.js по ключам dish.<идентификатор>.title и dish.<идентификатор>.text. При добавлении блюда добавьте его ключи в оба языка.
4. **Остальные тексты.** Замените значения переводов в TRANSLATIONS; соответствующие элементы в index.html связаны с ними через data-i18n. Не удаляйте ключи, используемые в разметке и скрипте.
5. **Фотографии.** Сейчас в проекте цветные SVG-заглушки. Файлы images/coffee.svg, images/dessert.svg, images/breakfast.svg и images/plate.svg используются в карточках меню. Замените их на фотографии размером от **1200 × 800 px** (соотношение 3:2). Шесть файлов images/gallery-coffee.svg, gallery-dessert.svg, gallery-breakfast.svg, gallery-interior.svg, gallery-table.svg и gallery-pastry.svg используются в галерее; рекомендуемый размер фото — от **1400 × 1000 px** (примерно 4:3). При замене SVG на JPG или WebP укажите новые имена файлов в script.js и в src изображений галереи в index.html. Сохраните подходящие тексты alt.
6. **Отзывы.** Демонстрационные отзывы находятся в index.html; замените их реальными данными. Дни недели переключаются между языками через data-i18n, а часы работы задаются в CONFIG.hours в script.js.

Название, адрес, меню и отзывы в этом демо вымышлены. Подставьте данные клиента перед публикацией его сайта.

## Публикация на GitHub Pages

1. Войдите в GitHub и создайте публичный репозиторий.
2. Загрузите в корень репозитория содержимое папки demo-cafe: index.html, style.css, script.js, README.md и папку images.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Укажите ветку main и папку / (root), затем нажмите **Save**.
6. После публикации откройте ссылку, указанную в разделе Pages. Убедитесь, что index.html лежит в корне выбранной папки.

## Публикация на Netlify

1. Войдите в Netlify и выберите **Add new site → Deploy manually** (в некоторых версиях интерфейса это называется **Netlify Drop**).
2. Перетащите папку demo-cafe целиком или ZIP-архив с её содержимым.
3. Дождитесь загрузки и откройте ссылку, которую покажет Netlify.
4. Сборочную команду и папку публикации задавать не нужно. При желании в настройках можно изменить имя сайта или подключить свой домен.

## Файлы проекта

- index.html — разметка и содержимое одностраничного сайта.
- style.css — цвета, мобильная вёрстка, адаптивные состояния и анимации.
- script.js — объект настроек CONFIG, переводы, переключение меню и галерея.
- images/ — локальные SVG-заглушки, которые можно заменить фотографиями.
